# Carros API

API REST desenvolvida em Spring Boot para gerenciamento de carros.

## Tecnologias

- Java
- Spring Boot
- Spring Data JPA
- MySQL
- Flyway
- Maven

## Banco de Dados

Banco: `carros`

Principais migrations:

- V1 - Criação inicial
- V2 - Ajuste dos tipos de latitude e longitude
- V3 - Recuperação do encoding UTF-8

## Executando

```bash
mvn spring-boot:run
```
